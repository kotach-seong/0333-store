# 근무 시작 전 점장 전화(00:00, 첫 손님 전). 받을 때까지 시계가 멈춘다.
# [DAY n] 아래에:
#   이름: 대사          대사창 한 칸(한 줄에 36자쯤까지)
#   수칙: 내용          전화를 끊으면 수첩 "야간 근무 수칙"에 번호를 붙여 적힌다(날마다 이어 붙음)
#   낙서: 내용          수첩에 번호 없이 적힌다
# 이상현상은 점장이 알려 준 날부터 나온다:
#   DAY 1 물건·CCTV / DAY 2 영수증 합계 vs POS / DAY 3 영수증 시각 /
#   DAY 4 영수증 손님 설명·번호 / DAY 5 없는 상품·돈 대신 신체·피 묻은 영수증

[DAY 1]
점장: 여보세요. 새로 온 야간 알바 맞지? 나 점장이야.
점장: 첫날이니까 딱 두 가지만 기억해.
점장: 하나. 손님이 계산대에 올린 물건을 잘 봐.
점장: 우리 가게에 없는 물건이 섞여 있으면… 받지 마.
점장: 둘. 계산할 땐 CCTV를 꼭 한 번씩 돌려 봐.
점장: 앞에 서 있는 손님이 화면에 안 찍혀 있거나,
점장: 화면 속 손님이 네 눈으로 본 거랑 다르게 생겼거나,
점장: 손님 뒤든 가게 밖이든, 없어야 할 게 같이 찍혀 있으면.
점장: 점검표에 "아니오" 하고 그냥 보내. 말 섞지 말고.
점장: 그리고... 새벽 3시 33분.
점장: 그때 계산대에 뭐가 오든, 절대 "정상"으로 마감하지 마.
점장: 무조건 "아니오"야. 시간 끌지 말고.
점장: 수칙은 수첩에 적어 둘게. 6시에 교대 오니까 그때까지만 버텨.
수칙: 계산은 손님이 계산대 앞에 왔을 때만 한다.
수칙: 계산대에 우리 가게 물건이 아닌 게 있으면 승인하지 말 것
수칙: 영수증과 CCTV 확인 후 인원이 다르면 승인하지 말 것
수칙: CCTV 속 손님이 눈앞의 손님과 다르면 승인하지 말 것
수칙: 새벽 3:33의 거래는 정상으로 마감하지 말 것

[DAY 2]
점장: 어제 수고했어. …별일 없었지?
점장: 오늘부터는 영수증도 봐야 돼.
점장: 영수증 합계랑 POS 화면에 뜬 금액. 그 둘이 똑같아야 정상이야.
점장: 가끔 안 맞는 게 있어. 기계 탓이 아니야. 그런 건 받지 마.
수칙: 영수증 합계가 POS 화면 금액과 다르면 승인하지 말 것

[DAY 3]
점장: …나야. 오늘은 시간.
점장: 영수증에 찍힌 시각이 지금 시계랑 맞는지 봐.
점장: 아직 안 온 시간이나 이미 지난 시간이 찍혀 있으면,
점장: 그 손님은 지금 여기 있으면 안 되는 사람이야.
점장: 받지 마. 알았지?
수칙: 현재 시각보다 미래의 거래, 과거의 거래는 승인하지 말 것

[DAY 4]
점장: 이제 좀 익숙해졌어? …목소리가 피곤하네.
점장: 영수증 맨 위에 손님 적히는 줄 있지.
점장: 그게 지금 앞에 선 사람이랑 맞는지 봐.
점장: 아저씨인데 아줌마라고 찍히거나, 글자가 깨져 있거나.
점장: 그리고 영수증 번호. 순서대로 가야 돼.
점장: 겹치거나 건너뛰면 그것도 안 돼.
점장: …전에 있던 애는 이걸 안 지켰어.
수칙: 영수증의 손님이 앞에 선 손님과 다르면 승인하지 말 것
수칙: 영수증 번호가 겹치거나 건너뛰면 승인하지 말 것

[DAY 5]
점장: 오늘이 마지막으로 알려 주는 거야. 잘 들어.
점장: 영수증에 계산대에 없던 물건이 찍혀 있으면 안 돼.
점장: 처음 보는 이상한 이름이 찍혀 있어도.
점장: 돈 대신 이상한 걸 내밀면… 그건 돈이 아니야. 알지?
점장: 영수증에 피가 묻어 있으면, 그건 더 말할 것도 없고.
점장: 이제 네가 아는 게 내가 아는 거 전부야.
수칙: 영수증에 계산대에 없던 물건이 있으면 승인하지 말 것
수칙: 돈이 아닌 것을 받으면 승인하지 말 것
